# Secure Key Generator

A lightweight, browser-based password generator with a simple responsive interface. Choose a password length and the character types to include, generate a password, and copy it to your clipboard.

## Features

- Adjustable length from 8 to 32 characters (16 by default)
- Optional uppercase letters, lowercase letters, numbers, and symbols
- Generates a password automatically when the page loads
- One-click clipboard copy
- No build tools or dependencies required

## Use it

### Run locally

1. Clone or download this repository.
2. Open `index.html` in a modern web browser.
3. Set the desired length and character options, then select **Generate Password**.
4. Select **COPY** to copy the result.

Clipboard access may require a secure context (HTTPS or localhost) in some browsers.

### GitHub Pages

This repository can be published as a static site with GitHub Pages. In the repository settings, enable Pages and select the `main` branch as the source. Once published, open the Pages URL to use the generator.

## Security note

Although the page is named Secure Key Generator, the current implementation selects characters using JavaScript's `Math.random()`, which is **not cryptographically secure**. Do not use passwords generated by this version to protect sensitive or important accounts. A production-ready password generator should use the browser's cryptographically secure `crypto.getRandomValues()` API and should be independently reviewed.

The generator runs in the browser and does not send the generated value to a server; however, this alone does not make the output suitable for security-critical use.
